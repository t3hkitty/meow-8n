Termux & Shizuku Architecture Guide

          
        

        

          

            
1. Overview: How Localhost n8n Operates on Android

            
n8n is a Node.js workflow orchestration engine. This app functions as a native Android client container, connecting directly to the locally bound server instance at http://127.0.0.1:5678 or https://localhost:5678.

          


          

            
2. Termux Installation Steps

            
    
              
  1. Install Termux from F-Droid (do not use Google Play version).
    2. 
              
  2. Install Termux:API and Termux:Boot (optional for autostart).
    3. 
              
  3. Open Termux and run the bootstrap command:
                
    pkg update -y && pkg install -y nodejs-lts python build-essential git openssl
npm install -g n8n pm2
    
              
    4. 
              
  4. Launch n8n via PM2 to ensure background execution:
                
    pm2 start n8n --name "n8n-local" -- --tunnel=false
pm2 save
    
              
    5. 
            

          


          

            
3. Battery Optimization & Background Execution (Android 12+)

            
Android's Phantom Process Killer and Doze mode may kill background Node.js processes. To ensure uninterrupted automation:

            
    
              
  • Disable Battery Optimization for Termux and n8n Local (Settings → Apps → Battery → Unrestricted).
    • 
              
  • If using Shizuku, run the following ADB command once via Shizuku/rish to disable phantom process limits:
                
    device_config put activity_manager max_phantom_processes 2147483647
    
              
    • 
              
  • Acquire a Termux Wake Lock by running termux-wake-lock or starting n8n via the provided starter script.
    • 
            

          

        

        

          
        

      

    


    
    

      

        

          
Local SSL & HTTPS Configuration

          
        

        

          
Running n8n over HTTPS locally enables full browser crypto APIs, clipboard features, and secure webhook tunnels.

          
          
Option A: Auto-Generate Self-Signed Certificate via OpenSSL in Termux

          
Run this script inside Termux to create a local certificate with SAN (Subject Alternative Name) for localhost and 127.0.0.1:

          
mkdir -p ~/.n8n-ssl && cd ~/.n8n-ssl
openssl req -x509 -newkey rsa:2048 -nodes \
  -keyout n8n-local.key -out n8n-local.crt -days 3650 \
  -subj "/CN=localhost" \
  -addext "subjectAltName=DNS:localhost,IP:127.0.0.1"


          
Option B: Run n8n with Local TLS Flags

          
export N8N_PROTOCOL=https
export N8N_SSL_KEY=~/.n8n-ssl/n8n-local.key
export N8N_SSL_CERT=~/.n8n-ssl/n8n-local.crt
export WEBHOOK_URL=https://localhost:5678/
n8n start


          
Android Network Security Configuration

          
This APK includes a custom network_security_config.xml that permits cleartext localhost traffic and trusts both user-installed CA certificates and system certificates, ensuring seamless local HTTPS loading.

        

        

          
          
        

      

    


    
    

      

        

          
Termux & Shell Helper Scripts

          
        

        

          

            
1. All-In-One Setup Script (setup-termux-n8n.sh)

            
#!/data/data/com.termux/files/usr/bin/bash
set -e
echo "==> Setting up local n8n environment on Android..."
pkg update -y
pkg install -y nodejs-lts python build-essential git openssl termux-api
npm install -g n8n pm2
mkdir -p ~/.n8n
termux-wake-lock
echo "==> Setup complete. Run 'n8n' or start via PM2."

            
          


          

            
2. Background Starter Script (start-n8n.sh)

            
#!/data/data/com.termux/files/usr/bin/bash
termux-wake-lock
export N8N_PORT=5678
export N8N_PROTOCOL=http
export N8N_ENFORCE_SETTINGS_FILE_PERMISSIONS=true
export WEBHOOK_URL=http://127.0.0.1:5678/
export GENERIC_TIMEZONE=America/Los_Angeles
export NODE_OPTIONS="--max-old-space-size=1024"
pm2 start n8n --name "n8n-local" -- --tunnel=false

Frequently Asked Questions

          
        

        

          

            
Q: Does this app require internet access to operate workflows?

            
No. When executing purely local automations (such as file transformations, local database queries, on-device webhooks, or local script calls), all execution stays strictly on 127.0.0.1 / localhost without sending telemetry or traffic externally.

          

          

            
Q: How does this app trigger Termux commands automatically?

            
The Android manifest declares the com.termux.permission.RUN_COMMAND permission, allowing this controller to send background intents directly to the Termux service to start, restart, or terminate the n8n daemon process.

          

          

            
Q: What is Shizuku used for?

            
Shizuku gives the app elevated shell permissions without root access. This is particularly useful for preventing Android from terminating the Node.js daemon and for executing ADB-level commands like disabling the phantom process killer.

          

          

            
Q: Can I use self-signed SSL certificates?

            
Yes. The app provides built-in OpenSSL generator commands and custom Android network security configurations allowing user CA trust and localhost certificate overrides.

          

          

            
Q: Where are my n8n workflows and SQLite database stored?

            
By default, n8n saves its database and encryption keys inside Termux's private data storage at ~/.n8n/database.sqlite and ~/.n8n/config.
